# Trumpify Prints · Live Demos

Live demos of apps built with [Trumpify Prints prompts on PromptBase](https://promptbase.com/profile/trumpify?via=trumpify). Each demo is one self-contained HTML file: no server, no account, no tracking. Names and data are invented samples.

**Open the demos:** https://trumpifyshopify-ctrl.github.io/
